# 💊 Farmácia United

Sistema de gerenciamento de estoque desenvolvido em PHP utilizando PDO, com foco em responsividade, organização de código e boas práticas de desenvolvimento web.

---

## 📌 Sobre o Projeto

O **Farmácia United** é um CRUD completo para controle de produtos de uma farmácia.  
O sistema permite:

- ✅ Cadastrar medicamentos/produtos
- ✅ Listar produtos em estoque
- ✅ Editar informações
- ✅ Excluir produtos
- ✅ Controlar quantidade em estoque
- ✅ Visualizar preços e fabricantes

O projeto foi desenvolvido como atividade prática acadêmica utilizando:

- PHP
- MySQL
- PDO
- HTML5
- CSS3
- Git/GitHub

---

# 🚀 Tecnologias Utilizadas
